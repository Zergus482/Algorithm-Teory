# Лабораторная работа №1: Базовые конструкции Python

Решение набора базовых практических заданий по Python, объединенных верхнеуровневым модулем, и покрытых тестами `pytest`.

## Структура проекта

* `task_00_distance.py` — расчет расстояний между городами.
* `task_01_circle.py` — площадь круга и проверка попадания точек.
* `task_02_operations.py` — расстановка арифметических знаков для получения числа 25.
* `task_03_favorite_movies.py` — работа со срезами строк.
* `task_04_my_family.py` — списки и подсчет суммарного роста семьи.
* `task_05_zoo.py` — операции со списками (вставка, расширение, удаление, поиск по индексу).
* `task_06_songs_list.py` — списки, словари и суммирование времени треков.
* `task_07_secret.py` — декодирование строки сложными и обратными срезами.
* `task_08_garden.py` — операции над множествами (`union`, `intersection`, `difference`).
* `task_09_shopping.py` — выбор двух минимальных цен в магазинах.
* `task_10_store.py` — подсчет остатков и стоимости партий товаров на складе.
* `main.py` — консольное меню для запуска любого задания.
* `test_tasks.py` — тесты для проверки корректности выполнения всех задач.
* `requirements.txt` — внешние зависимости.

## Установка и запуск

1. Склонировать репозиторий или перейти в папку с проектом:
   ```bash
   cd python_lab_01

2. Установить зависимости:
    ```bash
    pip3 install -r requirements.txt
3. Запустить интерактивное консольное меню (верхнеуровневый модуль):
    ```bash
    python3 main.py

##  Запуск тестов

1. Для проверки корректности выполнения всех модулей-заданий выполните команду:
    ```bash
    pytest test_tasks.py -v
